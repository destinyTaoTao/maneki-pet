# 将逐次确认后的官方通道发布列为未来目标

状态：已接受（2026-11-01，grill-with-docs Q3/Q6）；部分取代 [ADR-0002](./0002-skill-packages-and-platform-adapters.md) 的长期人工发布范围。

当前实现保持“AI 备料 + 人工发布 + 证据回流”。未来允许在平台权限获批、账号授权有效的前提下，经用户预览并逐次确认最终作品、账号与发布范围，由官方 API 实际发布，再保存作品标识并核验审核/可见状态。账号 OAuth 不等于批准每次发布，未知提交结果先对账；不把一次发布受理或人工填写回执当作真实公开成功。限定范围无人值守发布尚未定案。

选择此路线是因为单纯导出备料不能满足助理代办发布的目标；逐次确认与官方通道能限定当前承诺，但增加账号资质、凭证保管、状态恢复和副作用对账成本。继续保留 cookie 投稿、协议模拟、真实账号接管和客户端 UI 自动化的现有限制。对外评论/私信仍只生成建议，发送人工；本决策不修改 EverNook 仓库或其 spec，记忆系统也不获得发布权限。

本次查到抖音官方[创建视频文档](https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-video/video-create)列出 `video.create.bind` 权限申请及用户授权要求，因此不再把历史“代投稿全部收回”的判断作为永久产品限制。个人主体和用户账号能否获批仍待核实；权限、真实发布与故障恢复验收前不开放发布能力。接口/数据迁移在未来契约定案时说明，本轮无代码行为变化。
