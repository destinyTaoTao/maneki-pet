# 指定星期提醒的接入与验收

以 `4057063` 为基线，验收「每周一、三、五上午九点提醒我休息」。调用方沿用 `reminder_recurring` 授权。Runtime 将用户指定的 ISO 星期集合升序保存，按规则时区的本地日历认领，在调用通知器之前提交下一次日期。[README](../../README.md#weekly-reminders) · [契约](../architecture.md#weekly-reminders)

## 真实 dsh 调度

Windows x64、Node 24.12.0、dsh 0.2.2-rc.1。隔离 profile 使用本地确定性 Provider 驱动 dsh 原生对话循环，经实际 stdio MCP 创建、查询和取消同一个系列。重放创建、取消均返回首次回执。取消后重放旧创建请求，活跃列表仍为空。

| 上海本地时间 | 指定星期通知器调用数 |
| --- | --- |
| 11 月 23 日周一、25 日周三、27 日周五 09:00 | 各 1 次 |
| 11 月 24 日周二、26 日周四、28 日周六、29 日周日 09:00 | 均为 0 |
| 11 月 23 日同一时刻重启 | 0 |
| 11 月 30 日周一 09:00，系列已取消 | 0 |

每行均等待调度扫描完成。除同一时刻的再次重启，每天的对照规则都调用通知器一次。验收使用模拟时钟与注入通知器。在线模型自主选择工具、系统通知横幅和 macOS/Linux 实机体验待单独验证。[dsh 接入](../../apps/dsh-plugin/README.md#让-dsh-在指定星期提醒) · [可复跑脚本](../../scripts/acceptance-dsh-reminder-weekly.mjs)

## 契约回归

- API、SDK、CLI 和 MCP 并发提交相同请求，以不同排列传入同一星期集合，返回一致回执。重复星期和额外字段返回 400，复用 ID 改变星期集合或周期返回 409。独立凭证、身份隔离、精确取消和撤销后的管理员恢复均经本地 Runtime 实测。[跨入口回归](../../packages/cli/tests/weekly-reminders-integration.test.ts)
- 调度回归覆盖用户当地日期与 UTC 跨日、稀疏星期遇到 DST 缺失与重复分钟、同日时钟回拨、持久认领、配额共用和存储故障隔离。认领提交后到通知器受理前进程中断时，当次可能错过。[调度回归](../../packages/runtime/tests/daily-reminders.test.ts)

全仓构建、类型检查及按包串行测试通过，762 项通过，3 项按环境条件跳过。既有每日、工作日及两种改期的真实 dsh 脚本通过，插件打包清单包含指定星期 patch。
