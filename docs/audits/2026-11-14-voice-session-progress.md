# #66 · 语音、倾听动作与会话进度（进行中）

本记录是源码工作区的局部验证，不代表 #66 的 Windows 整体验收通过。基于 #65 的只读观察记录和既有按键语音链路实现，未扩展 dsh 权限，也未引入新的 Provider 或动作包格式。

## 本轮实现

- 录音时在主会话面板展示现有人物播放器，先播放歪头动作，再以 thinking 状态持续表达倾听；动作包缺省仍沿用已有回退。录音期间缓存最新宿主表情，抑制其他表达动作；停止录音后恢复最新状态，不改变会话观察事实。
- 实时聚合表情从其他状态进入等待且勿扰关闭时招手一次；初始快照、重复等待与录音期间不重播。该行为按聚合表情计算，并不承诺每个等待会话单独招手。
- 语音转写沿用现有主会话入口，进度查询与会话面板沿用 #65 的同一观察记录；朗读中再次按住沿用现有先停播再采集的逻辑。

## 续测：同音歧义和只读短句

用户同意一次真实测试短句仅在隔离进程内存暂存并用于本地对照；音频未写入文件或上传，比较后内存清零。同一录音以 whisper.cpp small 和官方 large-v3-turbo Q5 模型运行，均把“查看会话进度”识别为“查看绘画进度”；为 small 和 turbo 增加领域词提示仍相同。该现象与中文同音歧义一致，但不能由此排除所有设备和采集问题，也不能推断其他语音场景的准确率。

规则新增明确的只读短句“查看进度”，对支持的会话查询有限规范化繁体字；不把“绘画”或其他同音词猜测为“会话”。回归覆盖不相关命令不命中，以及正式 HTTP 语音转写、提交、无模型回答与观察记录的联动（ASR 在自动测试中为替身）。

真实麦克风续测中，small 模型先有一次误识别，随后识别出“查看進度”；主会话回答 A 等待、B 已完成。原生“会话”面板显示相同的来源、项目、完整 ID 与状态；用户确认听到播报并在再次按住时立即停止。本次 B 在查询前已完成，**不证明识别成功的一轮中 B 恰好在录音期间完成**；此前并发场景有动作确认但识别失败。输出仍受前 150 字的截短限制，长回答的语音可能不含所有会话，应以完整文字与面板为准。未进行准确率、延迟或资源统计，#66 整体出口仍需补足并发成功轮次和剩余验收项。

续测后 `pnpm -r build`、`pnpm -r typecheck` 通过；`pnpm -r test` 首次在 WebSocket 用例建立测试服务时因 `fetch failed / bad port` 失败，该用例独立复跑通过，全仓复跑通过（389 项通过、2 项设备测试默认跳过）。首轮失败未改断言或增加重试；随机端口问题仍需另行处理。

## dsh SenseVoice 隔离探针

使用 Windows、本机 dsh 0.2.1-rc.5 的实验性 speechToText + SenseVoice 插件、独立 dsh home 和独立 Runtime；SenseVoice INT8 模型由宿主准备并校验。临时回环桥仅用于探测：小招测试 Runtime 取得同一段真实麦克风音频后依次调用 dsh SenseVoice 和本地 whisper.cpp small，音频仅在进程内存及本机请求中使用，没有存录音文件或调用云端。该桥不具备正式的配对和授权协议，不作为正式功能。

两次测试均为用户所说“查看会话进度”：SenseVoice 均返回“查看绘画进度。”，Whisper 分别返回“查看繪畫鏡頭”和“查看繪畫進度”。样本太少，不能比较总体准确率；本样本证明宿主识别调用可行，但两者均未消除同音歧义，也未命中进度查询。

停止已核实的隔离 dsh 后，再次按键，临时桥没有切换识别器；小招显示 `asr_host_unavailable` 技术码，该提示不满足清晰降级要求。随后在小招主会话发送文字“查看进度”，界面正确显示来源已失联、最后等待状态及当前未知。此结果仅证明临时探针的失联行为和现有文字链路；正式桥的权限、清晰提示、取消和失联尚未实现或验收。保留本地/百炼既有生产代码与设置，本轮没有改用户安装或 profile。

## 安全收口与尚未完成的恢复

后续审查发现，宿主转写可触发个人事项写入、伪装 Runtime 的本机监听者可骗取宿主凭证，以及取消后宿主识别可能仍在运行。已先行提交补充契约 `48004f3`；工作区实现将宿主转写限制为只读会话进度查询、在同一 TCP 连接上验证 Runtime、在宿主确认停止前禁止新的采集。针对伪造待办、伪造身份、连接切换、取消和迟到结果的自动测试通过。

停止确认标记不包含音频，且在 Runtime 重启后仍保留。若 dsh 在确认停止前崩溃，原实例无法再发送确认，此时所有录音来源都会被阻止，文字和播放不受此限制。已增加设置页“恢复语音采集”：用户先退出相关 dsh 及识别进程，再通过原生对话框确认；仍有宿主心跳或活动工作时拒绝恢复。停止确认、隔离与恢复已作自动测试，原生恢复操作还未实机验收。最近的真实 dsh/SenseVoice 合成音频试验发生在本次身份校验和停止确认改动之前，不能证明最终代码的真实宿主链路。
