# Maneki 整体目标与架构审计（2026-10-30）

## 范围与结论

审计基线为 [v0.2 / 6f977e2](https://github.com/destinyTaoTao/maneki-pet/tree/6f977e2)，覆盖 README、architecture、roadmap 与 AGENTS；通过 grill-with-docs 的 grilling/domain-modeling 工作流，结合两项独立只读事实审计和两轮用户决策对齐，形成 v0.3。

结论：产品目标与模块方向保留，优先交付“可换装桌宠 + dsh 文字任务中间人 + 插件入口”。v0.2 的恢复、幂等、音频协调和发布边界存在缺口，已在 v0.3 规范中修订；这表示设计处置完成，不代表代码、安全机制、harness 能力或性能已经验收。仓库仍无应用实现。

规范以 [architecture.md](../architecture.md) 为准；[GLOSSARY.md](../../GLOSSARY.md) 只定义词义，[ADR-0001](../adr/0001-shared-local-runtime.md) 记录共享 Runtime 的取舍原因，本报告保存审计证据与处置，不作为第二份实现规范。

## 用户已确认的九项决策

两轮均明确答复“全部按推荐”；下表是已确认结论，不是待选建议。

| 决策 | 确认结论 |
|---|---|
| Q1 首版核心价值 | 可换装桌宠与真实 harness 文字任务中间人优先，语音/主动陪伴/提醒独立增量 |
| Q2 插件安装形态 | 安装一次共享本地 Runtime，插件不要求先打开桌宠 App |
| Q3 云端关闭范围 | 控制 Maneki 自身 Provider；外部 harness 的数据去向与云端使用另行授权，不声称全局离线 |
| Q4 收费授权 | 限定范围的交互调用显式启用后持续授权；主动收费调用独立启用与限额；购买/支付逐次审批 |
| Q5 音频与打扰词义 | 勿扰、语音输出关闭、麦克风禁用分别控制；勿扰不禁止用户主动交互 |
| Q6 harness 优先级 | dsh 先验证，pi 第二；具体 API/安全能力由工程核验，不提前声明已支持 |
| Q7 任务上下文 | 首版新建受控任务会话；已有会话仅观察，自己的任务可以补充输入/跟踪/取消 |
| Q8 审批入口 | harness 原生审批先行，宠物整任务授权保留；宠物内审批桥后续按能力扩展 |
| Q9 后台生命周期 | 关闭界面不停止后台跟踪，明确退出助理才停本机服务；外部任务取消另行核实，开机启动默认关闭 |

## 发现与处置

下列带章节编号的证据位置指 v0.2 基线；“补充复核”是 v0.3 草稿中继续发现并修订的衔接问题。问题是契约或目标边界缺口，未声称存在已运行漏洞。

| 发现 | 触发与影响 | v0.3 最小处置 | 必须执行的验证 |
|---|---|---|---|
| 审批回执丢失缺操作对账（§5.1/5.4） | 批准可能已消费并执行，再发新审批可能重复危险副作用 | 首版 native；未来 bridge 要求 operationId/摘要单次认领与操作查询，结果未知不换 ID 重试 | bridge 开放前注入执行后回执丢失、执行侧崩溃、过期/重复决策，证明不重复启动操作 |
| 恢复只有状态，无完整交付（§5.1/5.3） | Runtime 离线期间完成任务或出现问题，恢复后拿不到产物/原问题 | query 返回完整 TaskSnapshot；status_only 显式降级，首版执行接入须通过完整恢复 gate | 断开 Runtime 后完成/待输入/待原生审批，恢复后结果与等待详情一致 |
| 补充复核：上游查询/订阅存在窗口 | 查询得到 running 后、建立事件订阅前完成任务，Shell 快照无法补齐这段上游缺失 | await subscribe 就绪并缓冲，再 query；按源位置或经验证的等效机制合并，无法证明不声明 full | 在 query 返回前后注入 completed/输入已回答，不漏终态、不重开旧问题 |
| 请求 ID 作用域不同（§5.1/5.3） | 两个客户端相同 requestId 本地视为两单，下游可能合并 | clientRequestId 只作入口幂等键，事务分配全局 brokerRequestId 供下游提交与查询 | 跨客户端相同入口 ID、同客户端重发/换内容、重启对账 |
| 多 Shell 音频无 owner（§2.1/4.1） | 桌面与插件重复播报/采集、设备争抢 | Runtime 分配一次交互的唯一音频 owner 与过期租约，失联停止，其他界面只显示文字 | 多端同时使用、网络隔断、owner 退出/租约过期，不重复占设备 |
| Windows 优先与阶段出口冲突（roadmap M1/M2） | Windows 通过但缺其他平台设备，整个 M1 无法判定是否可进入 M2 | Windows 出口与 macOS/Linux 支持矩阵分开 | 只勾选实际通过平台，Windows 进入下一阶段不宣称其他平台支持 |
| 插件依赖桌宠 App、交付晚于可选功能（§2.3、roadmap M5） | 只装插件不能启动助理，文字插件还需等待语音/提醒开发 | 已安装共享 Runtime 的受控启动/管理，最小 dsh 插件前移 M2b | 无桌宠窗口启动/配对/退出、双入口启动、客户端卸载不影响其他任务 |
| 云端与付费语义模糊（§4.1/5.4/7.6） | Provider 开关被误认作禁止 harness 联网；每轮推理审批或任意后台花费 | Maneki 与 harness 授权分开；交互/主动调用与购买支付分开，金额无法核实时不虚称硬封顶 | 开关、数据目的地、主动授权/限额、计量失效与未知费用路径分别验证 |
| 静音混合三种含义（§4.2/4.3） | 勿扰时主动按键是否录音没有一致答案 | 统一术语与优先级，麦克风禁用/输出关闭不能被勿扰例外穿透 | 勿扰 + 主动交互、输出关闭 + ASR、麦克风禁用 + 任意入口的组合 |

## 剩余事实与实现 gate

- **dsh 接入**：新会话、原生审批实际可达、完整快照、输入与取消均需固定宿主版本实测。任一首版要求不满足就记录限制并提出目标/能力调整，不能默默改成别的 harness 或假接入。
- **共享 Runtime**：打包、可信启动、独立后台生命周期、管理入口、单实例与总资源需 M2 spike。仅把进程叫 sidecar 不代表退出父窗口后仍可用。
- **可选语音**：本地 TTS 的模型/引擎与许可、ASR 速度、多设备租约和音频权限需 M3 证据；不把本地/云端可配置等同于所有 Provider 行为一致。
- **第三方代码**：M6 隔离验证前没有动态执行安装入口。纯数据形象包与受信内置 Adapter/Provider 不混为一个安全等级。
- **平台与性能**：当前无程序可测；macOS/Linux 未在本机验证。内存、延迟与真实系统通知仍是目标，静态检查不替代设备验收。

本轮不继续就这些事实向用户索取判断；它们在实际实现前后通过 spike、契约测试与真实环境验证解决，证据若改变已确认产品承诺再提出决策。

## 2026-10-31 目标补充与第二轮决策对齐

用户补充七项目标（多 harness 插拔、全会话总览与介入、harness 上下文与外挂 MCP 记忆、组件插件化、用量限额、参考商业产品、灵动表现），经 grilling 三轮对齐形成 Q1–Q17 决策，同步 architecture/roadmap/GLOSSARY。要点：

| 主题 | 结论 |
|---|---|
| 会话介入分级 | `sessionOverview`（只读总览，默认最近 10 个）与 `externalReply`（仅非审批等待输入、按来源授权）为正式需求，M5 落地；审批仍走原生路由，接管/宠物审批桥维持 M5+ 另验 |
| 主/子会话 | 主会话为唯一常驻入口；子会话绑定 harness 会话/任务，项目上下文只在子会话内注入 |
| 会话数据来源 | Adapter 能力声明为准；本地扫描仅作特定 Adapter 内部实现并声明边界，Core/Gateway 不做跨 harness 通用扫描器 |
| 外挂记忆 | 与内置 SQLite 分层并存（背景知识 vs 结构化事实）；MCP 客户端接入；写回三档关闭/仅摘要/全量原始，默认全量原始（用户 2026-10-31 决策，授权页明示内容范围与数据去向）；外挂故障不阻塞提醒/派发；显式/隐式记忆分开开关；删除助理会话不删除外部副本 |
| 用量限额 | 单次调用/会话上下文/每日总额三层配置化，默认保守；限额与降额状态诚实呈现 |
| 主动性 | murmur 与每日简报触发器（确定性触发、LLM 只写话术、默认低频/关闭、纳入防打扰预算）；当日失效、无料不发 |
| 插件化 | 全部内置能力走同一插件接口；第三方可执行维持 M6 隔离验收；纯数据包可早开放 |
| 里程碑落位 | 限额→M3；murmur/简报→M4；会话总览/介入与外挂记忆→M5 |

GLOSSARY 新增主会话、子会话、会话总览、碎碎念、外挂记忆五个术语。参考产品调研（ChatGPT Agent/Pulse/Memory/Projects、Meta AI、Grok companions）由子代理完成并保存工作记录，借鉴项已并入上述决策；成长/养成系统记为非核心彩蛋，不进里程碑。

边界：本轮为设计定案，不代表任何新能力已实现或验收。新增实现 gate：dsh 会话总览/回答等待输入的真实能力（M5 前 spike）、外部记忆服务协议与故障语义（M5 spike）。本轮变更未运行 build/test（仅 Markdown），提交前检查链接与契约示例语法。
