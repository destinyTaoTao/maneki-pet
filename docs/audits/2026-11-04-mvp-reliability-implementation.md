## 实现与迁移

- `express` 不能修改勿扰、派发/取消任务或管理凭证；勿扰写入改需 `settings`。现存凭证不自动提权，须从受信管理入口重新配对。
- WS 一次性票据绑定已鉴权客户端、原始 Origin（包括无 Origin）、scope 与 30 秒有效期；兑换时重新核对客户端有效性。撤销作废未用票据、关闭本客户端已有连接、移除表现租约，其他客户端保持连接。
- 请求体读取期间也可能撤销客户端，写入前重新鉴权；任务查询/取消统一核对来源归属，其他客户端和旧无归属记录均返回 404。
- SQLite v3 备份后事务新增可空 `client_id`；旧任务保留原状态，不猜测拥有者、不重派。新任务的认领/授权与 TaskRef 完整落库仍属 #11/#12，派发 gate 保持关闭。
- 桌面删除 `read_root_token` IPC 和 localStorage token 使用；native 通过已安装 sidecar 的固定管理模式，仅向 WebView 返回 `express,notify,settings` 客户端 token。凭证位于 Runtime 用户配置目录的 `desktop-client.json`；撤销后不静默重新配对。管理员显式移除此文件才重新配对，root 不写入该文件。
- 管理模式发送凭证前验证随机 challenge 的标准 HMAC-SHA256 证明，涵盖协议、实例及服务实际监听端口，并使用恒时比较。假同版本服务和向其他端口真实 Runtime 中继 challenge 的替身均拿不到凭证。证明不替代受信安装来源或 OS 用户隔离。
- 缺安装、超时、协议/身份不符、撤销及配置错误使用脱敏类别，并经 native 显示对应提示；未就绪不再宣称有不存在的自动重试。
- CLI 安装限制 JSON 各 1 MiB、实际素材单文件 64 MiB、合计 256 MiB，先核对真实文件，再以 64 KiB 缓冲计算摘要；固定已校验 JSON 快照，避免复制时换入另一份描述。
- 媒体验证只复用现有 FFmpeg/ffprobe，无新 npm/Rust 依赖；每次子进程检查限 30 秒、输出限 1 MiB。PNG/WebP 校对签名；WebM 检查 EBML DocType；QuickTime 检查前 4 KiB 内完整 ftyp 的原始 qt 品牌，旧无 ftyp MOV 明确受限。容器标记使用保留全部字节值的 latin1，禁止 ASCII 高位清除造成伪匹配。随后核对单视频流、像素预算和水平精灵条带，并完整解码。这个工具不是恶意媒体的 OS 沙箱。
