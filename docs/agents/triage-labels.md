# Triage Labels

| Canonical role | Tracker label | 含义 |
|---|---|---|
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格充分，可交给 Agent 实施 |
| ready-for-human | ready-for-human | 需要人工实施或判断 |
| wontfix | wontfix | 不予实施 |

类别标签沿用 bug / enhancement，与状态标签分开。
已分诊的 Issue 应具有一个类别和一个状态；
发现多个冲突状态时先核实，不自动覆盖。
