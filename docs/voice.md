# 按键语音：本地 / 百炼（2026-11-07）

近期只适配 dsh。更新桌面与 Runtime 后，通过 `/maneki assistant` 或桌宠打开同一助手。dsh 插件仍是入口，语音在桌面 Shell 与共享 Runtime 之间处理；无需把录音、密钥或语音设置交给 dsh。没有全局热键、唤醒词或常驻监听。

## 安装本地组件

ASR 由用户自行准备受信的 [whisper.cpp v1.9.5](https://github.com/ggml-org/whisper.cpp/tree/v1.9.5) Windows 构建及兼容的 GGML 模型，不自动下载或更新。实际验证的是该 tag 的 CPU 构建，`--version` 输出为 `whisper.cpp version: 1.9.5-dev`；程序仅接受 1.9.5 / 1.9.5-dev。其他版本不宣称兼容。该 tag 未提供本轮可用的预编译 release 附件；可按其官方 CMake 说明自行编译，不要把旧版 exe 改名冒充新版。

默认安装位置：

```text
%APPDATA%\com.manekipet.desktop\runtime\speech\whisper\
  whisper-cli.exe
  <该构建所需的相邻 DLL>
  model.bin
```

`model.bin` 是你选定的兼容模型文件。CLI 与模型路径固定，不接受项目配置指定任意程序或参数。缺文件或版本不符时明确报错。组件检测只检查 ASR 文件是否存在；真正调用还会核验 CLI 版本、依赖与模型能否加载。本轮 tiny 模型仅用于管道验证，中文命令存在误识别；请按自己的准确率、延迟与内存需求选模型并人工验收。

TTS 使用 Windows 本机已安装的 System.Speech 语音，通过系统 Windows PowerShell 5 生成内存 WAV。无需配置云端服务。点击“检测语音组件”列出可用的系统语音名称；名称可填入“系统语音名称”，留空使用系统默认。检测不会打开麦克风或播放声音。

## 启用与使用

1. 在助手“设置”中，按需启用“允许按键时使用麦克风”和“启用语音识别”，选择语言与识别服务后保存。两者都开启才允许输入。三项语音开关默认关闭；本地识别需先完成上方组件安装，百炼按下节配置。
2. 按住“按住说话”按钮，或聚焦该按钮后按住空格 / Enter。首次出现系统麦克风授权时由用户处理；权限等待期间松开会取消本轮，迟到的授权不会自行开始录音。授权后需要重新按住。
3. 松开后结束采集、转写并显示识别文本；仍有效的当前轮次自动提交同一对话入口，无需再点发送。每段最长 30 秒，至少 0.3 秒有效音频；静音、空结果、识别失败或取消不提交。点击“取消”、录音时失焦、隐藏/关闭面板或失联会停止本地音频。
4. 可独立开启“启用语音回答”并选择合成服务。只朗读本客户端主动请求的回复，或点击“朗读最后回复”；每次最多前 150 字。按键说话会先停止朗读，播放失败保留文字，不自动重播。主动提醒不自动播声。

语音复用现有个人对话、待办和提醒规则，不能批准工程操作。可说“待办：买牛奶”或“半小时后提醒我休息”，但 ASR 准确率取决于设备与模型；检查识别文本及实际办事反馈。关闭模型时仍可使用已有规则式文字/语音待办提醒。已经提交的事项不会因取消被假报撤销，需明确修改或删除。提交结果未知时先查历史与待办，不自动换请求 ID 重发。

录音由应用在内存处理，不存入 SQLite 或日志；成功提交的识别文字作为普通主会话消息本地保留。清空聊天会删除消息与摘要，保留去重墓碑及独立待办/提醒。选择百炼时相应录音/回复文字会发送云端；启用的对话模型仍按其独立本地/云端设置处理文字。

## 可选百炼在线语音

在同一设置面板中，识别服务与合成服务可分别选择“本地”或“阿里百炼（北京）”。例如在线识别配本地朗读，只需为识别选择百炼；云端识别不需要安装 whisper.cpp。首轮仅支持北京地域，不支持任意兼容 URL、新加坡或全双工。

1. 从百炼获取**北京地域**且有对应模型调用权限的 API Key，填入“百炼语音 API Key”。语音密钥与对话模型密钥独立；留空保留已有值，勾选删除可移除。密钥只由 Runtime 保存在用户目录，页面不会回显，不放入 dsh/profile/项目配置。
2. Workspace ID 可填实际业务空间 ID，使用其北京专属域名；留空使用 `https://dashscope.aliyuncs.com`。模型默认 `qwen3-asr-flash` / `qwen3-tts-flash`，在线音色默认 `Cherry`。更换时须确认账号支持该模型/音色；其他模型未实测，不自动猜测或切换。
3. 显式开启“允许 Maneki 自身云端调用”和需要的语音开关，并保存。ASR 发送本段录音，TTS 发送本次最多前 150 字回复；可能产生费用，不逐句确认。不会上传完整会话、待办列表或项目上下文。ASR/TTS 仍可分别关闭；全局云端关闭不阻断本地语音或文字待办。
4. “检测语音组件”对在线服务只检查本地配置和密钥文件，不联网核验权限、模型或余额；显示配置可用不代表真实账号调用成功。密钥、地域、权限或调用失败均明确报错，不自动回退、重试或改服务商。

关闭/更换设置会取消在途上传、下载与播放并隔离迟到结果，已经发送给服务商的数据无法撤回。在线 TTS 仅允许官方北京结果桶的 WAV，下载使用 HTTPS，不转发 API Key、不跟随重定向；签名 URL 不回显或入日志。服务商的数据留存与计费以其账号协议为准，本地清空不承诺删除云端副本。

实现依据 [Qwen-ASR 官方协议](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)及 [Qwen-TTS 官方协议](https://help.aliyun.com/zh/model-studio/qwen-tts-api)。本轮通过协议替身测试，**未使用真实账号做云端语音验收或计费调用**。首次真实使用还需核验账号权限、地域、音质、准确率和延迟，见[在线语音验证记录](./audits/2026-11-07-cloud-voice.md)。

## 更新与验证边界

SQLite v4 → v5 前生成 `runtime.db.bak-4`；更早版本按其源版本备份。回退时先停 Runtime，再显式恢复对应备份，不能把新库交给旧 Runtime。桌面与 Runtime 一起更新；旧客户端保存不含 voice 的设置时保留已有语音偏好。

在线语音不再升级 SQLite 版本，但旧 Runtime 的严格设置解析不认识新增字段。启用本轮版本前请先停止后台并备份 `runtime.db`；回退到在线语音之前的 Runtime 需要恢复该备份。现有 v4 迁移备份不代表在线语音更新前的最新数据，恢复旧备份会丢失其后的变更；不要仅凭“都是 v5”混用新旧 Runtime。

本轮未替换已安装应用。真实麦克风/扬声器、权限弹窗、噪声与口音、识别准确率、休眠/设备切换、安装器与长时资源仍需人工验收。macOS/Linux 未在本机验证；本地 ASR/TTS 只实现 Windows，云端 Provider 的其他平台设备/生命周期也未验收。前序自动化、原生构建和本地模型资源样本见[本地语音记录](./audits/2026-11-07-push-to-talk-voice.md)。
